# Quadratic Equation Solver (C++)

##  Описание

Консольная программа для решения квадратных и линейных уравнений вида:

ax² + bx + c = 0

Программа определяет:
- количество решений
- сами корни уравнения
- корректность входных данных

---

##  Входные данные

Три коэффициента:

a b c

(строки, ввод через пробел)

---

##  Выходные данные

Возможные ответы:

- `WRONG` — некорректный ввод
- `INF` — бесконечно много решений
- `NO SOLUTION` — решений нет
- `OK` — есть конечное количество решений
